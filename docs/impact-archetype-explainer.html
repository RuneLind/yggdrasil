7MCP usage

Before

{
  "tool": "impact",
  "args": {
    "qualified_name": "no.nav.melosys.domain.Behandling",
    "max_depth": 2
  }
}
// → 856 entries to sift through

After

{
  "tool": "impact",
  "args": {
    "qualified_name": "no.nav.melosys.domain.Behandling",
    "max_depth": 2,
    "archetype_exclude": [
      "test", "controller", "builder", "other"
    ]
  }
}
// → 302 architecturally-relevant entries
// → archetype_counts on response shows
//   pre-filter distribution for diagnostics
